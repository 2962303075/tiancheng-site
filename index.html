安装帮助

安卓电视 / 盒子怎么安装？
两种方式任选：
· 把对应 APK 拷贝到 U 盘，插入电视用文件管理器安装；
· 电脑连接 adb 后执行：adb install zhenguojian-0.2.76+84-arm64-v8a.apk
主流电视与盒子选 arm64-v8a，老旧 32 位设备选 armeabi-v7a。
下载的 Windows 绿色版怎么运行？
将 ZIP 完整解压到一个目录（不要直接双击压缩包），运行其中的 zhenguojian.exe 即可。建议解压到独立文件夹，不要放在下载目录里直接运行。
macOS 打开提示「无法验证开发者」怎么办？
首次打开在「系统设置 → 隐私与安全性」中点击「仍要打开」，或在终端执行 xattr -cr /Applications/甜橙短剧.app（把路径换成实际应用位置）。
遇到播放失败或剧集无法加载？
短剧源接口偶发限流，稍等片刻重试即可；可尝试切换剧集再返回。仍不行时检查网络，或等待下一次版本更新。
